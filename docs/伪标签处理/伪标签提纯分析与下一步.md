# 伪标签提纯分析与下一步

## 1. 当前问题判断

当前学生模型效果不稳定，核心问题已经不只是模型容量，而是**训练监督本身不够干净**。

从现阶段现象看，伪标签问题主要分成三类：

1. **整图级错误**
   - 某些图片里多个 prompt 都错
   - 更像域偏移、预处理失配、图像极性异常、低质图、teacher 整体误判

2. **类别级错误**
   - 某些类更容易乱打
   - 某些类更容易只覆盖目标一部分
   - 某些类只在高对比图上才比较稳定

3. **边界级错误**
   - mask 大致定位对，但边界不完整
   - 小目标、低对比目标更明显
   - 这类问题继续直接拿来强监督训练，会把学生模型往“粗定位但不闭合”的方向推

因此，当前最重要的工作不是继续盲目换模型或只改提交脚本，而是先把训练监督分层提纯。

---

## 2. 需要先明确的一点

**旧伪标签不能当真值。**

如果还是只拿旧伪标签和学生模型输出互相比较，那么能得到的是：

- 哪些样本**高风险**
- 哪些样本**不稳定**
- 哪些样本**大概率不适合直接用于强监督**

但不能仅凭旧伪标签自动证明：

- 某个 mask 的真实边界就是错的
- 某个漏检一定是错检
- 某个 prompt 的真实语义边界一定应当更大或更小

所以后续流程应理解为：

**自动风险筛查 + 小规模人工校准**

而不是：

**旧伪标签自证真伪**

---

## 3. 当前可做的伪标签提纯方式

即使没有人工真值，仍然可以先筛出大量高风险伪标签。

### 3.1 按置信度筛

适用：

- teacher 自己已经不确定的样本

做法：

- 不同类继续保留 class-specific threshold
- 不要回到统一阈值
- 对乱打多的类适度提阈值
- 对稀有类不要简单粗暴大幅提阈值，否则 recall 会直接塌

### 3.2 按整图异常筛

重点找：

- 一张图中多个 prompt 都异常
- 同图几乎所有 prompt 都命中错误区域
- 同图所有 prompt 都明显漏检

这类图通常不是某个类别问题，而是整图质量或域问题，优先进入 `denylist`。

### 3.3 按图像质量分桶筛

建议至少统计：

- 亮度
- 对比度 `std`
- 清晰度 `Laplacian`

目标是回答：

- 哪些类只在高对比图上准
- 哪些类在低对比图上系统性掉点
- 哪些 source 的图整体更不稳定

### 3.4 按掩码形态筛

高风险形态包括：

- 掩码极碎
- 掩码极细长
- 大面积糊成一片
- 贴边严重
- 面积异常偏大或偏小

这类样本即使 hit=true，也可能不适合直接当高质量监督。

### 3.5 按增强一致性筛

对同一张图做轻量变换后，如果 teacher 输出差异很大，说明该伪标签稳定性差。

适合测试的轻量变换：

- 反色统一前后
- CLAHE 前后
- 轻微 resize
- 轻微 crop / pad

如果同一目标在这些扰动下结果大幅波动，应视为高风险样本。

---

## 4. 当前不能指望自动完成的部分

以下问题不能只靠旧伪标签自动解决：

1. 真实边界到底应该在哪里
2. 低对比目标到底是 teacher 漏掉了，还是本来就不存在
3. 某类 prompt 的语义是否整体漂移
4. 某些系统性漏检是否来自 teacher 本身能力上限

因此需要引入**小规模人工复核集**。 

建议：

- 每个主要类别先抽 `20 ~ 50` 张高风险图
- 每类至少覆盖：
  - 高分命中样本
  - 低分命中样本
  - 明显漏半样本
  - 明显乱打样本

人工复核不是为了全量标注，而是为了校准“自动筛查规则是否真的抓到了问题”。

---

## 5. 后续处理原则

建议把伪标签分成三档，而不是简单二元“留/删”。

### A 档：高质量

特征：

- 高置信
- 整图稳定
- 掩码形态正常
- 轻量增强后一致

处理：

- 直接保留
- 作为强监督主力样本

### B 档：可疑但可用

特征：

- 目标大致对
- 但边界不完整或质量一般
- 或图像质量较差，但不是整图级错误

处理：

- 保留
- 训练时降权
- 必要时做边界弱监督或 ignore band

### C 档：高风险

特征：

- 整图级异常
- 低置信且不稳定
- 多 prompt 同时异常
- 掩码形态明显异常

处理：

- 先剔除
- 或进入人工复核池

## 6. 对学生模型训练的直接影响

### 6.1 不能只训练正样本

之前 `CLIPSeg` 训练集基本只保留了 `hit=True` 的正样本，这会导致模型：

- 学不会拒识
- 遇到完整 task 时更容易乱打

后续必须补两类负样本：

1. **整图级空样本**
2. **局部背景负样本**

### 6.2 对边界残缺样本不能做强监督

如果 teacher 只框出目标一部分，继续硬逼学生拟合整张 mask，会让学生稳定学歪。

可选处理：

- 直接过滤最差样本
- 对边界区域降权
- 只保留核心区域做强监督

### 6.3 不要在主线没稳前继续盲加新类

在主 5 类伪标签质量没有明显改善前，不建议急着把尾类大量并进主训练集。

更高优先级是：

- 先稳住已有主类
- 先补拒识能力
- 先把整图级脏标签剔掉

## 7. 建议的执行顺序

### 第一步：先做自动风险分析

目标：

- 找出最常乱打的类
- 找出最常漏半的类
- 找出只在高对比图上好的类
- 找出“全 prompt 都错”的图

工具：

- `src/tools/analyze_prompt_predictions.py`

输出：

- `per_class` 错误统计
- `all_prompts_wrong_images`
- 按对比度分桶的表现差异

### 第二步：产出一版坏图名单

建议生成：

- `bad_images_denylist.txt`

优先放进去的图：

- 多 prompt 同时异常
- 明显整图域偏移
- 质量极差且 teacher 明显乱打

### 第三步：按类调阈值

原则：

- 乱打多的类：提阈值
- 漏半多的类：先别只提阈值，先看是否属于边界残缺问题
- 稀有类：保守调，不要一口气砍没

输出：

- 一版新的 `pred_train_tasks_v2.json`

### 第四步：引入负样本/空样本

至少补两种：

1. 完整图级空样本
2. 局部背景负样本

目标：

- 让学生模型学会“没有目标就输出空”

### 第五步：人工复核小集合

对自动筛出的高风险样本做小规模人工核查，确认：

- 自动规则抓得准不准
- 哪些类真正值得继续保留
- 哪些 source 应该整批降权或剔除

### 第六步：再训学生模型

等新的伪标签版本和负样本机制准备好后，再继续训 `CLIPSeg` 或其他学生模型。

---

## 8. 当前阶段的推荐结论

当前阶段最值得投入的不是：

- 再换一条全新模型路线
- 只改提交推理脚本
- 盲目继续往训练集中加新类别

而是：

1. 先做伪标签风险筛查
2. 先做坏图剔除
3. 先按类提纯
4. 先补拒识负样本

一句话总结：

**现在最该做的不是“重新生成全部伪标签”，而是先把最伤训练的那批系统性脏标签和缺失的拒识监督处理掉。**
