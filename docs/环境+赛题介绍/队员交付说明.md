# 环境配置指南

## 1. 装 Python 环境

```powershell
# 安装 Anaconda → 打开 Anaconda Prompt，执行：
conda create -n raytron python=3.10 -y
conda activate raytron
```

## 2. 装 PyTorch（CUDA 版）

```powershell
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

## 3. 装项目依赖

```powershell
pip install numpy pillow timm ftfy regex iopath typing_extensions huggingface_hub einops pycocotools opencv-python tqdm scipy
```

## 4. 解压项目文件

拿到 `raytron_source.zip`，解压到本地。补上模型和数据：

```
raytron_project/
├── model/sam3.pt          ← 按官方赛题下载，放这里
├── test/data1~7/          ← 按官方赛题下载，放这里
└── src/                   ← 脚本目录（已包含）
```

## 5. 运行

```powershell
cd raytron_project

# 生成任务 JSON
python src/gen_val_tasks.py

# 推理
python src/prompt_test.py
```

## 6. 验证环境

```powershell
python -c "import torch; print('CUDA:', torch.cuda.is_available()); from inference import load_model; print('OK')"
```

输出 `CUDA: True` 和 `OK` 即配置成功。
