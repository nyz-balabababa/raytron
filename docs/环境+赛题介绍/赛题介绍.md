# 赛题二：红外智感—红外开放世界全模态分割挑战

## 一、赛题背景

红外成像技术凭借穿透烟尘、夜间清晰成像以及感应热能的特性，在电力巡检、森林防火、智能安防及自动驾驶辅助感知等领域具有不可替代的地位[reference:0]。

然而，相比日臻成熟的可见光视觉算法，红外领域面临两大技术瓶颈[reference:1]：

1. **标注成本极高**：海量红外数据缺乏高质量掩码标注，人工标注费时费力；
2. **模型泛化性差**：针对特定类别训练的模型难以适应开放世界中的未知目标。

近期，SAM-3（Segment Anything Model 3）在可见光领域实现了革命性的零样本分割，但其巨大的参数量级（通常为数亿级）使其难以部署在算力受限的红外终端设备上[reference:2]。

## 二、赛题任务

参赛者需构建一个支持 **“图像+文字描述”输入** 的分割模型：

- **输入形式**：一张图像（红外或可见光）+ 一段描述性文字提示（如：“发热异常的绝缘子”、“草丛中隐蔽的车辆”）。文字提示中英文不限，可以是一句话也可以是一个名词，最多不超过10个单词[reference:3]。
- **输出形式**：目标物体的二进制分割掩码，掩码大小应与输入图片一致。若同一张图中存在多个符合描述的目标，输出应为所有该类目标掩码的并集[reference:4]。

## 三、核心技术挑战

### 1️⃣ 大规模自监督学习

在无人工标注的情况下，高效利用 50,000+ 张红外图片。训练图片来自5个不同场景的不同分辨率红外实拍图片，包含不同的数据格式（png、jpg）。最终的测试集场景涵盖训练集的5个场景，并在此基础上加入其他场景，以测试泛化性能[reference:5]。

### 2️⃣ 极小目标分割

红外场景常涉及远距离探测，模型需对尺寸 **小于 8×8 像素** 的目标保持高灵敏度。极小目标占测试集总数量的10%，指标计算方法和普通目标相同[reference:6]。

### 3️⃣ 大参数量模型蒸馏

将 SAM-3 的知识有效迁移到轻量级模型，参数量限制 **≤ 300M**，内存占用限制 **≤ 1.5G**。

## 四、数据支持

### 训练集（大规模无标注）

- **规模**：超过50,000张红外图像；
- **特性**：涵盖城市安防、电力巡检、自然荒野、工业园区等多种复杂背景；
- **标注规则**：官方不提供任何人工标注，需选手自主标注学习；
- **其他**：选手也可使用其他公开数据集（可见光或红外均可）[reference:8]。

### 决赛封闭测试集

决赛采用完全黑盒的红外数据，系统通过 ann_id（任务唯一索引）建立“图片+提示词”与“真值标签”的对应关系。测试集包含：

- **通用类别（General）**：常规红外目标；
- **极小目标专项（Small）**：尺寸小于8×8像素的目标；
- **长尾/泛化类别（Zero-shot）**：训练集中未出现过的特种红外目标；
- **极端环境**：高噪声、强遮挡、超视距等场景[reference:9]。

## 五、提交要求

### Docker 镜像提交模式

本赛题全程采用 Docker 镜像提交模式：

1. 指定基础镜像：`supervisely/sam3`，Tag：`1.0.6`；
2. 选手需在此 Docker 中进行开发，将代码放在 `/raytron/code/` 下面；
3. 最终模型路径为 `/raytron/code/model/sam3.pt`[reference:11]；
4. 模型权重以 FP32 格式存储，参数量不得超过 300M[reference:12]。

### 存储格式

为降低存储开销，掩码需采用 **COCO RLE（Run-Length Encoding）格式** 编码[reference:13]。

## 六、评审标准

- **初赛**：MIOU（红外测试集平均交并比）[reference:14]；
- **决赛**：围绕分割精度、推理效率和泛化性等方面展开[reference:15]。
