# 环境配置指南

## 1. 硬件要求

- NVIDIA 显卡，显存 ≥ 8GB（推荐 RTX 3060 及以上）
- 磁盘空间 ≥ 20GB（模型文件 3.4GB + 数据）
- 内存 ≥ 16GB

## 2. 软件安装

### 2.1 CUDA 环境

```bash
# 方案 A：安装 CUDA Toolkit 12.x（推荐）
# 下载: https://developer.nvidia.com/cuda-downloads

# 方案 B：仅用 conda 管理（更简单）
conda create -n raytron python=3.10 -y
conda activate raytron
conda install cudatoolkit -c nvidia
```

### 2.2 PyTorch

```bash
# CUDA 12.x
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

### 2.3 项目依赖

```bash
pip install numpy>=1.26 pillow timm>=1.0.17 ftfy==6.1.1 regex \
            iopath>=0.1.10 typing_extensions huggingface_hub einops \
            pycocotools opencv-python tqdm scipy
```

## 3. 项目文件

需要复制以下文件到目标机器：

```
raytron_project/
├── inference.py          # 官方推理脚本（必须）
├── sam3/                 # SAM3 模型源码（必须）
├── model/                # 模型权重 sam3.pt（必须）
├── assets/               # 分词器词表（必须）
├── src/                  # 你的脚本（必须）
├── test/                 # 数据（自行准备）
└── requirements.txt      # pip 依赖列表
```

**模型文件 `model/sam3.pt` 单独分发**（3.4GB，太大不适合放代码仓库）。

## 4. 运行

```bash
cd raytron_project

# 生成任务 JSON
python src/gen_val_tasks.py

# 推理
python src/prompt_test.py
```

## 5. 常见问题

**Q: 显存不够？**  
减小 `MAX_VIS_IMAGES` 或去掉预处理 (`ENABLE_PREPROCESS = False`)。

**Q: import inference 报错？**  
确保 `inference.py` 在项目根目录，运行 `sanity_check.py` 验证环境。

```python
# sanity_check.py - 放在项目根目录运行
import torch; print("CUDA:", torch.cuda.is_available())
from inference import load_model; print("inference OK")
import cv2; print("opencv OK")
from tqdm import tqdm; print("tqdm OK")
```
