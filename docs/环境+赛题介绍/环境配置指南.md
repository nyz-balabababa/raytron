# 环境配置指南

## 1. 硬件要求

- NVIDIA 显卡，显存 ≥ 8GB（推荐 RTX 3060 及以上）
- 磁盘空间 ≥ 20GB（模型文件 3.4GB + 数据）
- 内存 ≥ 16GB

## 2. 软件安装

### 2.1 RTX 4090 推荐环境

4090 机器推荐用 conda 安装 CUDA 版 PyTorch，再用 `pip --no-deps` 安装项目依赖，避免 `ultralytics / ultralytics-thop / timm` 通过 pip 重新解析并覆盖成 CPU 版 PyTorch。

```powershell
conda create -n raytron python=3.10 -y
conda activate raytron

conda install pytorch torchvision torchaudio pytorch-cuda=12.4 -c pytorch -c nvidia -y

python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"

pip install --no-deps -r src\require_4090.txt
```

CUDA 检查期望输出中必须包含：

```text
True
NVIDIA GeForce RTX 4090
```

### 2.2 为什么要用 `--no-deps`

`src/require_4090.txt` 没有直接写 `torch / torchvision / torchaudio`，但以下包会声明 PyTorch 依赖：

- `ultralytics`
- `ultralytics-thop`
- `timm`

如果直接运行：

```powershell
pip install -r src\require_4090.txt
```

pip 可能会重新安装 PyPI 上的 `torch / torchvision`，覆盖 conda 装好的 CUDA 版，导致 `torch.cuda.is_available()` 变成 `False`。因此 4090 环境安装项目依赖时必须使用：

```powershell
pip install --no-deps -r src\require_4090.txt
```

### 2.3 如果 PyTorch 已被覆盖

重新安装 CUDA 版 PyTorch：

```powershell
conda activate raytron
conda install pytorch torchvision torchaudio pytorch-cuda=12.4 -c pytorch -c nvidia -y
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

## 3. 项目文件

需要复制以下文件到目标机器：

```
raytron_project/
├── inference.py          # 官方推理脚本（必须）
├── sam3/                 # SAM3 模型源码（必须）
├── model/                # 模型权重 sam3.pt（必须）
├── assets/               # 分词器词表（必须）
├── src/                  # 你的脚本（必须）
├── test/                 # 数据（自行准备）
└── src/require_4090.txt  # 4090 依赖列表
```

**模型文件 `model/sam3.pt` 单独分发**（3.4GB，太大不适合放代码仓库）。

## 5. 常见问题

**Q: 显存不够？**  
减小 `MAX_VIS_IMAGES` 或去掉预处理 (`ENABLE_PREPROCESS = False`)。

**Q: import inference 报错？**  
确保 `inference.py` 在项目根目录，运行 `sanity_check.py` 验证环境。

**Q: 为什么 4090 上没有调用 GPU？**  
先检查当前环境是否是 CUDA 版 PyTorch：

```powershell
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

如果输出是 `False` 或 `CPU`，通常是安装依赖时没有使用 `pip install --no-deps -r src\require_4090.txt`，导致 CUDA 版 PyTorch 被覆盖。

```python
# sanity_check.py - 放在项目根目录运行
import torch; print("CUDA:", torch.cuda.is_available())
from inference import load_model; print("inference OK")
import cv2; print("opencv OK")
from tqdm import tqdm; print("tqdm OK")
```
