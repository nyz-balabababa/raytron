## 一、总体原则

1. **验证集不能参与训练集**（哪怕训练集只用于生成伪标签），否则会高估效果。
2. **验证集要能代表最终测试场景**：你的赛题测试集大概率也是红外、多场景（公路、室内、野外、俯视小目标等），验证集必须覆盖这些场景。
3. **对样本极少的子集（data3, data4, data7）做特殊处理**：数量太少（<50），如果随机分，验证集可能分到0张或1张，无法评估。建议把这些小数据集**全部或大部分划入验证集**，同时训练集中保留少量。
4. **保持主线各类别（人、车、建筑、树、动物）在验证集中的比例与整体大致相似**，但因为你有隐式的目标类别（prompt列表），划分时最好按**图像级场景**分层，而不是按文件名随机。

## 二、验证集划分方案（建议）

### 步骤 1：按原始数据集（data1/3/4/5/6/7）分别处理

| 数据集 | 总张数 | 建议验证集张数 | 比例 | 理由                                                     |
| :----- | :----- | :------------- | :--- | :------------------------------------------------------- |
| data1  | 35000  | 3500           | 10%  | 样本充足，随机采10%足以代表俯视小目标场景                |
| data3  | 29     | 29             | 100% | 模拟从未见过的场景                                       |
| data4  | 24     | 24             | 100% | 同上                                                     |
| data5  | 8531   | 850            | 10%  | 公路+室内密集场景，10%足够                               |
| data6  | 10000  | 1000           | 10%  | 野外动物场景                                             |
| data7  | 1433   | 430            | 30%  | 办公室场景，主线与尾类混杂（人、电脑、垃圾桶等），多保留一些验证 |

**验证集总张数** ≈ 3500 + 20 + 15 + 850 + 1000 + 430 = **5815 张**
**训练集总张数** ≈ 31500 + 9 + 9 + 7681 + 9000 + 1003 = **49202 张**
验证集比例 ≈ **10.6%**，非常合理。

> 注：data3/data4 虽然比例高，但绝对值只有几十张，不会让验证集过大，且能保证这些罕见场景被评估到。

### 步骤 2：在每个数据集内部做**分层随机采样**

不要简单随机抽文件，因为每个数据集内可能还有子场景（例如 data5 同时包含公路和教室）。如果你有更细的目录结构或文件名规律，可以进一步分层。
如果没有元信息，就按**文件名哈希**做均匀随机采样，例如：

python

```
import hashlib
def is_val(filename, val_ratio=0.1):
    return int(hashlib.md5(filename.encode()).hexdigest(), 16) % 100 < val_ratio * 100
```

这样可以保证随机且可复现。

### 步骤 3：固定验证集列表后，**永远不再变动**

一旦划分好，将验证集图片路径写入一个 `val_list.txt`，后续所有实验（prompt 调优、学生模型验证）都基于同一个验证集。

## 三、验证集的使用方式（对应你的规划）

根据你文档中的路线图，验证集需要支持：

1. **阶段1：prompt 调优**
   - 用验证集 + 官方 SAM3 跑不同 prompt 候选。
   - 通过可视化抽查 + 激活率统计，选最佳 prompt 集合。
   - 此时不需要真值。
2. **阶段2：生成伪标签后，验证伪标签质量**
   - 可以用验证集上官方 SAM3 teacher 的预测结果作为伪标签的“参考”（本质上就是伪标签自身）。
   - 但你要抽检一小部分（比如100张）人工确认伪标签是否合理。
3. **阶段3-5：训练学生模型后，在验证集上评估**
   - 计算学生模型预测 vs 伪标签的 mIoU、Dice。
   - 这是迭代优化学生模型的主要指标。
4. **最终提交前**：
   - 人工抽查验证集上学生模型的预测结果，确保不比官方 SAM3 差。
   - **注意**：官方测试集是封闭的，你不能用它做任何验证，所以验证集的代表性至关重要。

补充一点：当前任务 JSON 与 teacher 伪标签的生成入口已经固定为：

- `src/prompt/gen_val_tasks.py`
- `src/prompt/generate_sam3_pseudo_labels.py`

如果要在验证集阶段排除明显坏图，优先通过统一 denylist 控制，而不是手工改动任务 JSON 内容：

- `src/tools/build_unified_denylist.py`
- `noisy_data/unified_denylist.txt`

## 四、一个需要注意的细节：data1 内部可能有“不知道要识别啥”的图片

你在 data1 中标注了“不知道要识别啥”。这些图片本身没有问题，只要你的 prompt 列表中不包含对应目标，SAM3 输出应为空 mask。验证集抽到时，正好可以检查模型是否产生了假阳性。

**建议**：在验证集中，对每张图记录下“你预期应该出现的目标类别（即使不完全确定）”，方便后续判断。例如：“这张俯视图里很可能有小车和人，但树和建筑也可能出现”。

补充：如果图像里出现 `computer`、`trash can`、`cable connector` 这类目标，当前应优先视为**尾类专项样本**，不要因为它们比例低就反向影响主线五类的验证集设计。
