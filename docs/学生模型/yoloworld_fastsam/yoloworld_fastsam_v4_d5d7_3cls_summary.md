# YOLO-World + FastSAM v4 d5&7 三类尾类实验总结

## 一、实验目标

本轮 `v4` 实验只保留 3 个尾类：

- `computer`
- `trash can`
- `cable connector`

实验目的不是追求最终提交模型，而是验证以下问题：

1. 这 3 个尾类在 `d5&7` 伪标签上是否可学
2. 引入空标签负样本后，是否能提升泛化或抑制误检
3. 负样本的“数量”和“抽样方式”哪个更影响结果

固定设置：

- 训练伪标签：`test/prompt_test_output/train_d5&7_tasks/pred_train_d5&7_tasks.json`
- 验证伪标签：`test/prompt_test_output/val_d5&7_tasks/pred_val_d5&7_tasks.json`
- 训练列表：`test/train_list_d5&7.txt`
- 验证列表：`test/val_list_d5&7.txt`
- 正样本图：396 张
- 验证正样本图：143 张
- YOLO 输入尺寸：800
- FastSAM 输入尺寸：1024
- 多尺度类别：`computer`、`cable connector`

## 四、分项分析

### 4.1 纯正样本版是当前最优

纯正样本版的整体表现最好：

- `overall mIoU = 0.3823`
- `trash can = 0.4432`
- `computer = 0.3612`
- `cable connector = 0.2801`

这说明：

- 这 3 个尾类并不是完全不可学
- 当前 `world + FastSAM` 路线在小规模尾类上，首先能靠高密度正样本学到一部分信号
- 当前最强基线仍然是“不加负样本”的版本

### 4.2 随机负样本 `1.5x` 明显过强

随机抽取 `1.5x` 负样本后，结果显著恶化：

- `overall mIoU` 从 `0.3823` 跌到 `0.1562`
- `trash can` 从 `0.4432` 跌到 `0.0985`

说明：

- 对这批尾类来说，负样本压力过大时，模型会快速变保守
- 最先崩掉的是 `trash can`
- 当前伪标签质量和样本规模还不足以支撑高比例空标签负样本

### 4.3 随机负样本 `1.0x` 是当前“带负样本版本”的最好点

将负样本比例从 `1.5x` 降到 `1.0x` 后，结果明显回升：

- `overall mIoU = 0.3345`
- `trash can = 0.4045`

虽然仍然不如纯正样本版，但它是当前“引入负样本后”效果最稳的一版。

可以理解为：

- 负样本不是完全不能加
- 但当前最合适的量级大约在 `1.0x` 左右
- 再继续增大，收益变成负收益

### 4.4 分层负样本 `1.0x` 没有带来提升

分层负样本 `1.0x` 这次抽样命中为：

- `family = 279`
- `bucket = 117`
- `source_fallback = 0`

这说明代码里的分层逻辑是生效的，396 张负样本全部来自“同文件族 / 同编号桶”的更近场景候选，而不是全局随机补齐。

但最终结果反而更差：

- `overall mIoU = 0.2518`
- `trash can = 0.2960`
- `cable connector = 0.1604`

结论是：

- 当前定义下的“分层负样本”更像硬负样本
- 对目前这 3 类的伪标签质量和模型能力来说，这种负样本太难
- 当前瓶颈已经不只是“负样本不够聪明”，而是模型和监督本身对硬负样本承受力有限

## 五、结论

### 5.1 当前排序

按 `overall mIoU` 排序：

1. 纯正样本：`0.3823`
2. 随机负样本 `1.0x`：`0.3345`
3. 分层负样本 `1.0x`：`0.2518`
4. 随机负样本 `1.5x`：`0.1562`

### 5.2 当前阶段的可操作判断

- `v4` 路线已经证明：这 3 个尾类在 `d5&7` 上是可学的
- 当前最优方案仍是纯正样本版
- 如果正式训练必须引入部分空标签负样本，随机 `1.0x` 是目前最稳的折中点
- 分层负样本在当前设定下没有收益，不建议继续投入太多时间细调

### 5.3 后续建议

当前更值得推进的方向：

1. 保留纯正样本版作为 `v4` 最佳 tail-head 基线
2. 如果要做“带负样本版本”，优先保留随机 `1.0x`
3. 不再继续深挖分层负样本
4. 后续应把精力转回：
   - 伪标签质量提升
   - 类别阈值与过采样调优
   - 是否并回正式 8 类训练体系

## 六、一句话总结

`YOLO-World + FastSAM v4` 在 `d5&7` 三类尾类实验中，已经证明尾类可学；但当前最优仍然是“纯正样本训练”，负样本策略最多只能做到次优补充，尚未成为主提升项。
