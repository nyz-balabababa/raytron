### 为什么 6 个 prompt 也能训练泛化能力

你要训练的不是"记住 6 个 prompt 对应什么 mask"，而是 **text embedding → mask 的映射函数**。文本编码器（CLIP）是冻结的、预训练好的，它已经把开放世界的语义编码好了。解码器只需要学会"从语义向量中提取视觉定位信号"这个能力。

打个比方：CLIP 已经认识 40 万种语义，你只需要在 6 个语义向量上教会解码器"怎么看图找东西"。推理时换一个 prompt，CLIP 照样能编码它，解码器如果真学会了"根据语义找目标"，就能泛化。

### 不额外跑 SAM3 就能扩充 prompt 的方法

你已经有 39K 张图上 6 类 prompt 的 SAM3 mask。对每张图，**把同一个 mask 对应到多个同义词/近义词上**：

```
原数据:  图像 + "car"      → mask_car
扩充后:  图像 + "car"      → mask_car
         图像 + "vehicle"  → mask_car     ← 同一份 mask，不重新推理
         图像 + "汽车"     → mask_car
         图像 + "轿车"     → mask_car

         图像 + "person"   → mask_person
         图像 + "human"    → mask_person
         图像 + "行人"     → mask_person
         图像 + "pedestrian" → mask_person
```

**不增加任何 SAM3 推理开销**，只是训练时把同一张图同一份 mask 配不同的 prompt 喂给模型。效果是：解码器学会"car/vehicle/automobile/汽车"这 4 个不同的 CLIP 向量应该映射到同一个视觉响应模式。这个能力天然泛化到没见过的词。
