# 学生模型选型方案

## 约束条件

- 输入：单张图像（红外/可见光）+ 文本 prompt
- 输出：所有符合描述的目标掩码的**并集**（单张二值 mask）
- 参数量 < 300M
- 训练数据：SAM3 生成的 39,104 张伪标签（5 类）
- 场景特点：小目标多 + 目标密集

---

## 第一优先级：原生支持文本提示（推荐主力）

| 模型 | 参数量 | 推理 | 小目标 | 密集 | 开箱程度 | 备注 |
|------|--------|------|--------|------|----------|------|
| **YOLO-World + seg head** ⭐ | ~80M | ~20ms | 强 | 强 | 高 | Ultralytics 官方开源，开放词汇检测，可加分割头。工程成熟，部署方便 |
| **CLIPSeg (BiomedCLIP)** ⭐⭐ | ~150M | ~50ms | 中 | 中 | 高 | HF 一行导入，冻结 CLIP 上训练轻量解码器。红外泛化潜力大 |
| **Grounding DINO + EfficientSAM** ⭐⭐ | ~250M | ~80ms | 强 | 强 | 中 | 两阶段检测+分割，密集场景 NMS 天然优势，精度上限最高 |
| **Mask2Former + CLIP encoder** | ~200M | ~60ms | 中 | 强 | 低 | 密集场景 SOTA，需改分类头为 CLIP 实现开放词汇 |
| **OwlViT + SAM tiny**⭐⭐ | ~100M | ~100ms |  |  |  | 做对比实验，探求上限 |

---

## 第二优先级：SAM 蒸馏变体

| 模型 | 参数量 | 特点 |
|------|--------|------|
| **EfficientSAM3** | 轻量 | 专为从 SAM3 蒸馏设计，2025 年新工作，完美契合知识蒸馏路线。实践案例少 |
| **EfficientSAM** | 轻量 | 成熟稳定，参数量减少 20 倍。不支持文本提示，需与 CLIP 结合改造 |
| **MobileSAM** | ~9M | CNN 架构极致轻量优化。对小目标和红外场景保持能力待验证 |
| **EdgeSAM** | ~7M | 边缘设备优化。小目标退化风险最高 |
| **TinySAM** | ~10M | 结构搜索蒸馏。需要额外 fine-tune 适配红外域 |

---

## 第三优先级：红外专用轻量检测器（闭集，需改造）

| 模型 | 参数量 | 推理 | 小目标 | 原任务 | 备注 |
|------|--------|------|--------|--------|------|
| **ALSS-YOLO** | 1.5M/2.2M/2.9M | ~15ms | 强 | TIR 无人机红外野生动物检测 | 自适应通道分离+坐标注意力，需加分割头 |
| **LE-IRSTD** | ~6M | ~20ms | 强 | 红外小目标通用检测 | MBConv+可变卷积，需加分割头 |
| **HFMNet** | ~6M | ~20ms | 强 | 红外小目标特征增强 | 交叉池化+混合特征挖掘，需加分割头 |

> **共同缺陷**：三者均为闭集检测模型，不支持文本输入。如果赛后场景固定为 5 类（person/car/building/tree/animal），可牺牲文本输入换取极致轻量化和速度。需自行添加分割头并将 Open-Vocabulary 替换为 5 类 Softmax。

## 实验计划

```
阶段一：裸跑对比（epochs=50~100）

  首选： YOLO-World + seg head（快速落地）
  次选： CLIPSeg（学术路线，极限轻量）
  标杆： Grounding DINO + EfficientSAM（精度上限）
  探索： Mask2Former + CLIP（可选）

阶段二：选 winner 对比蒸馏方案

  如果 winner 效果满意：
    → 尝试 EfficientSAM3 / MobileSAM 蒸馏，进一步压缩模型
  如果 winner 不理想：
    → 回退到 ALSS-YOLO / LE-IRSTD 固定类别路线

阶段三：增强 + 微调 winner

阶段四：如果 computer 类 mAP < 0.1，加 loss 权重或舍弃
```

---

## 推荐路线总结

| 目标 | 方案 |
|------|------|
| **快速落地** | YOLO-World + seg head，利用开放词汇能力直接微调伪标签 |
| **探索上限** | Grounding DINO + EfficientSAM 作为对比实验 |
| **学术路线** | CLIPSeg，追求极致轻量 |
| **蒸馏路线** | EfficientSAM3（坚持 SAM3 蒸馏计划，但需放弃或改造文本提示） |
| **兜底方案** | ALSS-YOLO / LE-IRSTD + seg head（放弃开放词汇，固定 5 类） |
