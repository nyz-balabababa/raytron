## 一、总体路线

当前阶段采用的是 **伪标签监督学习（Pseudo-Label Supervised Learning）**——用 SAM3 生成 mask 硬标签，训练轻量学生模型去拟合。相较于真正的知识蒸馏（需要对齐中间特征、软标签概率分布、attention map），伪标签监督只传递了 SAM3 的最终输出，没有传递其内部的推理过程。但考虑到比赛中 SAM3 仅用于生成训练数据、不参与推理评估，伪标签监督是当前约束下最高效的替代方案。

```
SAM3 伪标签（6 类，~39K 训练 / ~4.5K 验证）
         │
         ├── 实验一：YOLOv11-seg（闭集分割）     ← 基线，验证伪标签可用性
         │
         ├── 实验二：CLIPSeg（端到端开放词汇）   ← 伪标签监督，文本条件分割
         │
         └── 实验三：YOLO-World + FastSAM（两阶段） ← 开放词汇对比方案
```

三个实验共享同一套数据处理管线（分级置信度过滤、反色统一、过采样），仅模型架构和训练策略不同，确保对比公平。

## 二、实验一：YOLOv11-seg 闭集基线

**目的**：验证 SAM3 伪标签能否训出轻量红外分割模型。这是蒸馏路线的地基——如果伪标签连闭集模型都训不动，开放词汇更无从谈起。

**方案**：用 Ultralytics YOLOv11-seg 在 SAM3 伪标签上训练 6 类固定分割。两阶段训练（150+50 epoch），高分辨率（1280），专门针对红外小目标优化的数据增强（关 mosaic/mixup、水平翻转、亮度微调）。

**结论**：验证了伪标签可用性 + 红外域迁移可行性 + 小目标检测策略有效性。产出了后续实验都在用的 baseline 数据处理管线。

> 详细文档：[yolov11/yolo11n-seg.md](yolov11/yolo11n-seg.md)

## 三、实验二：CLIPSeg 伪标签监督

**目的**：用 CLIPSeg（CLIP 视觉 + CLIP 文本 + FiLM 解码器）验证"文本 prompt 进入模型后，轻量 backbone 能否通过伪标签监督学会 SAM3 的语义定位能力"。

严格来说这不是知识蒸馏——CLIPSeg 只学习了 SAM3 的掩码输出（硬标签），没有对齐 SAM3 的中间特征、logits 分布或 attention map。它本质上是一个文本条件的学生模型，通过拟合 SAM3 的输出间接学习文本→掩码的映射关系。后续可以在当前框架上加入软标签蒸馏或特征对齐 loss，演进为真正的知识蒸馏。

**方案**：基于 HuggingFace `CIDAS/clipseg-rd64-refined`。CLIP 文本编码器冻结，视觉编码器微调（lr=1e-5），FiLM 解码器从头训练（lr=1e-4）。200 epoch 单阶段训练，warmup + 余弦退火。

**关键设计**：
- 逐样本置信度加权 loss（SAM3 score 作为权重，floor=0.7）
- 动态 prompt 增强（50% 概率替换为同义描述）
- 反色统一（偏度检测 + blackHot 文件名 + 均值兜底）
- CLIP 标准化（均值/标准差与预训练一致）
- RLE→PNG 磁盘缓存（首次解码后存盘，后续直接加载）

> 详细文档：[clipseg/clipseg_v1.md](clipseg/clipseg_v1.md)

## 四、实验三：YOLO-World + FastSAM 两阶段

**目的**：用"检测 + 分割解耦"方案与 CLIPSeg 端到端方案对比，验证哪种开放词汇路线更适合红外域。

**方案**：两阶段管线。
- **阶段一**：YOLO-World v2 做开放词汇检测（仅训 bbox，FastSAM 不训练）。伪标签 RLE → 归一化 bbox 格式
- **阶段二**：FastSAM 零样本分割——用 YOLO-World 输出的 bbox 作为位置 prompt，逐框分割后合并为并集 mask

**关键设计**：
- 训练仅 100 epoch（微调而非从头训），patience=10 早停
- 推理时加载两个模型（YOLO ~80M + FastSAM ~22M），两阶段串联
- 同义词泛化测试：用 "vehicle"→"car" 等映射评估开放词汇能力
- 数据处理（过滤、反色、过采样）与 CLIPSeg 完全一致

> 详细文档：[yoloworld_fastsam/yoloworld_fastsam_v1.md](yoloworld_fastsam/yoloworld_fastsam_v1.md)

## 五、三个实验对比

| | YOLOv11-seg | CLIPSeg | YOLO-World + FastSAM |
|---|---|---|---|
| 类型 | 闭集分割 | 端到端开放词汇 | 两阶段开放词汇 |
| 输入 | 图像 | 图像 + 文本 | 图像 + 文本 |
| 训练 | 分割头全量训 | 解码器 + 视觉编码器微调 | 仅检测头微调 |
| 参数量 | ~9.4M | ~150M（~30M 可训练） | ~102M |
| 数据格式 | polygon | RLE→mask（在线解码） | bbox |
| 分辨率 | 1280 | 1024 | 800 |
| Epoch | 150+50 | 200 | 100 |
| 训练方式 | 伪标签监督（闭集） | 伪标签监督（开放词汇） | 伪标签监督（两阶段） |
