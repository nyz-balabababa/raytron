# docs 目录说明

这份文档用于说明 `docs/` 下各文件夹的定位，避免后续文档越写越多后发生混淆。

---

## 1. 顶层目录

当前 `docs/` 下主要有 4 个一级目录：

- `前期准备`
- `学生模型`
- `环境+赛题介绍`
- `数据增强`
- `伪标签处理`

另有根目录文档：

- `提交指南.md`
- `日志.md`
- 本文件 `docs目录说明.md`

---

## 2. 前期准备

路径：`docs/前期准备/`

用途：

- 记录数据准备、验证集划分、质量分析、训练前工作流
- 记录 prompt/伪标签生成阶段的基础性结论
- 属于“训练前的通用底层资料”

适合放这里的内容：

- 数据集统计
- 质量分析
- 验证集划分规则
- prompt 测试总结
- 训练前统一流程说明

不建议放这里的内容：

- 某个学生模型版本的专项实验记录
- 某个具体训练脚本的版本演进

---

## 3. 学生模型

路径：`docs/学生模型/`

用途：

- 记录所有学生模型路线的实验、总结、版本演进、后续计划

当前子目录：

- `clipseg/`
- `yolov11/`
- `yoloworld_fastsam/`

### 3.1 clipseg

路径：`docs/学生模型/clipseg/`

用途：

- 存放 CLIPSeg 路线的训练设计、实验记录、loss 设计、mask 缓存、提交方向说明

### 3.2 yolov11

路径：`docs/学生模型/yolov11/`

用途：

- 存放 YOLOv11-seg 闭集基线实验
- 用于验证伪标签、数据转换、分割训练链路是否可用

### 3.3 yoloworld_fastsam

路径：`docs/学生模型/yoloworld_fastsam/`

用途：

- 存放 `YOLO-World + FastSAM` 路线的版本演进、实验总结、copy-paste 尝试、world 路线后续计划

当前这一类文档适合放这里：

- `v1 / v2 / v3 / v4 / v5` 技术总结
- 版本演进总览
- `world` 专项实验记录
- `copy-paste`、裁剪增强等与 `world` 路线直接相关的设计文档

---

## 4. 环境+赛题介绍

路径：`docs/环境+赛题介绍/`

用途：

- 存放赛题规则、环境配置、官方交付要求、项目目录要求
- 这是“规则层”和“运行环境层”的文档目录

适合放这里的内容：

- 环境配置指南
- 赛题介绍
- 官方推理要求
- 队员交付说明

不建议放这里的内容：

- 模型实验结果
- 数据增强方案

---

## 5. 数据增强

路径：`docs/数据增强/`

用途：

- 单独存放各种数据增强方案设计
- 目的是把“增强策略”从“模型版本总结”里拆出来，减少混淆

适合放这里的内容：

- Copy-Paste 设计
- 正样本裁剪增强设计
- `person@data1` 极小目标增强方案
- 后续如果做 hard negative / crop / mix 策略，也放这里

当前已建议存放：

- `computer / trash can` 裁剪增强方案
- `person@data1` 极小目标裁剪增强方案

---

## 5.1 伪标签处理

路径：`docs/伪标签处理/`

用途：

- 单独记录伪标签质量分析、风险筛查、提纯规则、坏图剔除策略
- 目的是把“teacher 输出质量问题”从“学生模型训练总结”里拆出来

适合放这里的内容：

- 伪标签提纯分析
- 官方 SAM3 代码整理与伪标签生成方案
- denylist 设计
- class-specific threshold 调整依据
- 自动筛查规则与人工复核结论

## 7. 推荐归档规则

为了后面不乱，建议按下面规则放文档：

- 和数据准备、prompt、验证集划分有关：放 `前期准备`
- 和具体模型路线实验有关：放 `学生模型`
- 和官方规则、环境、推理入口有关：放 `环境+赛题介绍`
- 和增强策略设计有关：放 `数据增强`
- 和伪标签质量分析、清洗、提纯有关：放 `伪标签处理`

如果一个文档同时涉及“模型路线”和“增强方案”，建议：

- 主体是实验结果：放 `学生模型`
- 主体是方法设计：放 `数据增强`

---

## 8. 当前使用建议

你后面最容易混的是这几类文档：

- `yoloworld_fastsam` 版本总结
- `copy-paste / crop` 增强方案
- 训练前流程总结

建议使用方式：

- 想找 `world` 某一版实验结果：去 `docs/学生模型/yoloworld_fastsam/`
- 想找增强方法设计：去 `docs/数据增强/`
- 想找 prompt、伪标签、验证集规则：去 `docs/前期准备/`
- 想找伪标签提纯和坏图筛查：去 `docs/伪标签处理/`
- 想确认提交规则和环境：去 `docs/环境+赛题介绍/`
