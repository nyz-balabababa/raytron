# 最终提交论文梗概：项目阶段性工作与技术路线整理

## 0. 项目总体思路

本项目面向红外图像开放词实例/语义分割任务，整体技术路线经历了从 **SAM3 teacher 伪标签构建**、**学生模型基线筛选**、**伪标签质量治理** 到 **ESAM-CCLIP-11 主线优化** 的多阶段迭代。

项目的核心目标是：在模型参数量、推理速度和开放词分割能力之间取得平衡，构建一个能够在红外图像中根据文本 prompt 输出对应二值 mask 的学生模型。最终模型主线逐步收敛到：

```text
EfficientSAM 图像编码器
+ Chinese-CLIP 文本编码器
+ 自定义 FiLM fusion decoder
+ 11 类 clean rare 伪标签
+ threshold sweep / postprocess
```

当前项目仍处于最后冲分阶段，主要围绕 ESAM-CCLIP-11 的 `lite`、`mid`、`split -> fullset`、`rare-repair-lite` 等训练策略继续压分。

## 1. 第一阶段：Prompt 选择与初始 6 类伪标签构建

### 1.1 Prompt 候选实验

项目初期首先围绕 SAM3 teacher 的开放词检测能力进行了 prompt 实验。做法是选取多组候选 prompt，在验证集上统计不同 prompt 的激活率、平均分数和平均实例数量，用于判断哪些类别更适合作为初始训练标签。

早期实验中，使用全验证集 `val_list.txt` 对以下 6 个 prompt 进行了检测：

```text
person
car
building
tree
computer
animal
```

对应统计中可以看到，`person / car / building / tree` 的激活率较高，`animal` 相对较低，`computer` 极低但仍作为早期尾类候选被保留。相关记录中，`person` 激活率约 61.9%，`car` 约 47.8%，`building` 约 47.0%，`tree` 约 46.7%，`animal` 约 8.7%，`computer` 约 0.5%。

因此，项目早期确定了 6 类主线：

```text
person / car / building / tree / animal / computer
```

同时也进行过同义词 prompt 对照，例如：

```text
human / vehicle / house / plant / pc / wildlife
```

但后续发现部分同义词 prompt 的稳定性不如原始类别名，因此初始训练仍以原始 6 类为主。

### 1.2 初始伪标签生成流程

初始伪标签生成流程主要包括：

```text
图片列表 + prompt 列表 + denylist
  → 生成 task json
  → 调用官方 SAM3 teacher 推理
  → 输出 prompt-style pred json
  → 保存 stats / kept / skipped / meta
```

其中，任务生成脚本负责把 `train_list.txt / val_list.txt` 展开成“每张图 × 每个类别”的任务格式；SAM3 伪标签生成脚本则基于官方 `SAM3` 推理链路生成与训练流程兼容的 `pred_*.json`、`stats_*.csv` 和 `kept_*.txt`。

## 2. 第二阶段：伪标签可视化抽查与基础清洗

### 2.1 可视化小界面

为了判断 teacher 伪标签是否可用于训练，项目制作了交互式伪标签浏览器，用于人工抽查不同类别的伪标签质量。

该工具支持查看：

```text
原图
mask 叠加
bbox 叠加
按文件夹筛选
按类别筛选
按命中/高分/低分/漏检筛选
旧伪标签与新伪标签差异
分歧样本 TopK
```

该浏览器主要用于抽查 `pseudo_A/B/C`、旧 teacher 与新 teacher 的差异，以及检查 mask 转 bbox 是否合理。

### 2.2 图像层面的基础清洗

在伪标签生成前，项目也做了图像质量分析和坏图清理。主要包括：

```text
文件名规则分析
图像亮度/对比度/清晰度/噪声/SNR/动态范围统计
极小分辨率图片处理
伪彩色图检测
截图/边框/文字 UI 叠加检测
人工坏图维护
统一 denylist 构建
```

其中，自动异常检测包含彩色图、准星、截图边框、文字/UI 叠加等检测项，输出 `clean_outliers.csv` 和统一坏图名单 `unified_denylist.txt`。

后续 teacher 生成阶段还加入了自适应红外预处理，包括：

```text
伪彩色检测转灰度
黑热/白热反色统一
动态 CLAHE
动态降噪
动态锐化
```

这些预处理用于提升 SAM3 teacher 在红外图像上的稳定性。

### 2.3 按类别做过的基础处理

根据现有脚本和文档，目前可以明确整理出的类别处理包括：

#### old 类处理

```text
person / car / animal:
  在 manifest 策略阶段有 tiny 小目标保护设计，避免小目标被过度过滤。

building:
  在 manifest 策略阶段做过更严格清理，防止大面积建筑伪标签噪声影响训练。

tree:
  在不同模型线中尝试过多尺度和后处理，但后续发现 tree 多尺度并不总是稳定收益。
```

其中，`pseudo_label_policy.py` 明确封装了 A/B/C 权重、新旧伪标签融合、`person/car/animal` tiny 保护、`building` 更严格清理、`selected_hit`、`mask_source`、`sample_weight` 等策略。

#### rare / 新类处理

后续新增类处理中，`xiyou.py` 记录了较完整的 rare prompt 合并与清洗策略：

```text
truck / bus → car
dustbin / garbage bin → trash can
laptop / monitor / keyboard → computer

window / door / fence / motorcycle 保留为独立 rare 类
pole / street light / utility pole 跨 prompt 合并为 pole_light
```

同时，一些不稳定或不采用的 prompt 被直接丢弃，例如：

```text
traffic light
sign
screen
bicycle
backpack
sliding door
tunnel light
transmission tower
electrical cabinet
```

该脚本还对 `window / door` 做了减去 car 重合区域的处理，以减少车窗、车门等与车辆区域重叠带来的伪标签污染。

在 rare 合并过程中还使用了：

```text
score 阈值
最小面积过滤
IoU / containment 去重
边界平滑度过滤
碎片比例过滤
每图每 prompt 上限
每图每目标类上限
形态学 close / open
连通域提取与 top-k 保留
```

例如，`xiyou.py` 中配置了 `MIN_AREA`、`IOU_THRESH`、`CONTAINMENT_THRESH`、`SMOOTHNESS_THRESH`、`FENCE_MAX_SMOOTHNESS`、`FENCE_MAX_FRAGMENT_RATIO` 等过滤参数，并对不同 prompt 设置了独立 score 阈值。

## 3. 第三阶段：学生模型基线实验

在初始 6 类伪标签基础上，项目开始实验多种学生模型路线。早期主要尝试了：

```text
CLIPSeg
ESAM + Chinese-CLIP + 自定义 decoder
YOLO-World + FastSAM
```

### 3.1 CLIPSeg 基线

CLIPSeg 是早期较重要的基线模型。该路线保留了：

```text
image + text prompt → binary mask
```

的开放词分割形式，适合作为 teacher 伪标签蒸馏下的轻量文本分割模型。

后续 `clipseg-v5-opt` 文档中可以看到，该路线最终演进为：

```text
CLIPSeg 原架构
+ prompt pool
+ 轻负样本
+ BCE / Dice / Focal
+ rare oversample
+ 每类阈值
+ 多 prompt 融合
+ 按类后处理
```

并且 11 类版本中明确去除了 `computer`，最终类别为：

```text
person / car / building / tree / animal
trash can / window / door / fence / pole_light / motorcycle
```



CLIPSeg 的意义主要是：

```text
1. 提供早期可用基线；
2. 保持开放词 prompt 分割形式；
3. 验证伪标签训练链路是否有效；
4. 作为 ESAM 线后续优化的对照。
```

### 3.2 ESAM + Chinese-CLIP + 自定义 decoder

ESAM 线的基础结构为：

```text
EfficientSAM image encoder
+ Chinese-CLIP text encoder
+ FiLM fusion decoder
```

其目标是利用 EfficientSAM 更强的图像结构特征，同时保留 Chinese-CLIP 的文本 prompt 表达能力。

后续 ESAM-CCLIP-11 文档中明确写到，该路线实际由：

```text
img_encoder = PureImageEncoder
txt_encoder = FreezeTextEncoder
decoder     = FiLMFusionDecoder
```

组成，其中 image encoder、text encoder 和 fusion decoder 分别复用早期 `src/hanxue` 中的模块。优化重点不是改 backbone，而是扩展到 11 类、稳定 prompt prototype、稳定热启动和训练流程。

### 3.3 YOLO-World + FastSAM

YOLO-World + FastSAM 是另一个早期重要实验线，其核心思路是：

```text
SAM3 伪标签提供监督
YOLO-World 学开放词检测
FastSAM 在推理阶段根据检测框补分割
最终用 mask mIoU 判断两阶段路线是否有效
```

该路线经历了 v1 到 v5 的迭代：

```text
v1：跑通两阶段路线
v2：叠加小目标和稀有类技巧
v3：回收无效技巧，形成稳定 6 类基线
v4：针对 computer / trash can / cable connector 的尾类实验
v5：将尾类并回主线，验证数据链路和尾类稀释效应
```



从实验总结看，YOLO-World + FastSAM 的特点是训练较快，适合快速验证类别不平衡、小目标和尾类数据增强策略；但最终整体效果没有成为最优主线，因此后续更多作为实验验证工具和对照路线。

## 4. 第四阶段：YOLO-World 上的小目标与类别不平衡实验

YOLO-World 虽然整体效果没有成为最终主线，但由于训练速度较快，项目将其作为快速实验平台，用于验证类别不平衡、小目标和尾类增强策略。

### 4.1 尾类实验

YOLO-World v4 专门聚焦尾类：

```text
computer
trash can
cable connector
```

该阶段主要验证：

```text
1. 尾类是否可学；
2. 负样本策略是否有帮助；
3. 阈值和过采样对尾类是否有效；
4. 尾类是否更依赖伪标签清洗。
```

总结中记录到，这些尾类并非完全不可学，但 `trash can` 和 `cable connector` 对样本干净度更敏感，负样本策略并不是主要提升项。

### 4.2 computer / trash can 裁剪增强

针对 `computer` 和 `trash can` 目标小、样本少、容易被背景淹没的问题，项目设计了裁剪增强方案，用于替代效果不稳定的离线 Copy-Paste。

核心思路是：

```text
从原始正样本图出发
围绕目标 bbox 裁剪局部 patch
让目标在 patch 中相对更大
同步生成新图片、新标签和 pred_json
```

对于 `trash can`，裁剪策略更偏紧，推荐外扩倍数为 `2.0x ~ 3.0x`；对于 `computer`，由于更依赖上下文，推荐保留更多环境信息，外扩倍数为 `3.0x ~ 4.5x`。

该方案中特别强调不做跨图 Copy-Paste，原因是 Copy-Paste 容易破坏红外热分布、引入拼接边界，并且前期实验中收益不稳定。

当前 `offline_crop_tail.py` 已实现的约束包括：

```text
只从高质量正样本中抽取
裁剪框做轻微中心抖动
主目标必须满足保留比例、最小 mask 像素数和 patch 面积占比
非主目标按连通域检查保留比例
导出 YOLO 标签类顺序固定对齐 world v4
输出 source_usage.csv
输出 preview 可视化结果
```



### 4.3 该阶段结论

这一阶段的结论可以写为：

```text
YOLO-World 路线训练速度较快，适合作为尾类、小目标和类别不平衡策略的快速验证平台。实验表明，computer / trash can 等尾类并非完全不可学，但单纯依赖过采样、负样本或裁剪增强并不能稳定提升最终分割指标，尾类效果更依赖伪标签质量与后续主模型的表达能力。因此后续项目重心重新回到伪标签治理和 ESAM-CCLIP 主线。
```

## 5. 第五阶段：回到伪标签质量治理与 Manifest 探索

在基础模型实验后，项目发现 CLIPSeg 基线可用但分数仍不够高，YOLO-World 尾类实验也无法从根本上解决问题，因此重新回到伪标签本身进行更细致的质量分析。

### 5.1 旧版 teacher 与新版 teacher 对比

项目使用 `compare_pseudo_labels.py` 对新旧伪标签进行系统比较，分析内容包括：

```text
hit 状态翻转
新旧 mask IoU 变化
不同类别变化幅度
teacher 更保守还是更激进
连通域数量
面积变化
碎片程度
显著分歧样本
```

该工具适用于比较不同阈值、不同预处理版本，以及旧 6 类伪标签与新伪标签之间的差异。

### 5.2 A/B/C 三档质量分级

随后项目使用 `refine_pseudo_labels.py` 对当前 teacher 伪标签做质量分档，将样本拆成：

```text
A：高质量
B：可疑但可用
C：高风险
```

并输出：

```text
pseudo_A.json
pseudo_B.json
pseudo_C.json
review_list.txt
denylist.txt
refine_summary.json
```

这一步不是直接生成训练集，而是为后续 manifest 训练样本决策提供上游分级依据。

### 5.3 Manifest 构建

在 A/B/C 分档基础上，项目使用 `build_train_manifest.py` 将：

```text
pseudo_A.json
pseudo_B.json
pseudo_C.json
旧版伪标签
refine_summary.json
denylist
```

整合成训练脚本可以直接消费的 manifest。

manifest 中每条 record 包含：

```text
image_path
prompt
grade
include_in_train
selected_hit
sample_weight
mask_source
is_tiny
flags
disabled_reason
rle
```

它负责训练样本是否纳入、正负样本属性、权重分配、building 清理和新旧标签选择，但不负责训练阶段的负样本采样比例、boundary ignore 或 loss 计算。

### 5.4 Manifest 阶段结论

虽然 manifest 阶段帮助项目系统分析了伪标签质量，并验证了不同等级样本的价值，但后续训练发现，直接使用 manifest 提纯版本训练的效果不如最初 6 类 CLIPSeg 基线。这说明过强的样本准入过滤可能导致 recall 下降，尤其是在当前评测更依赖掩码召回的情况下，过度“干净”的训练集并不一定带来更好的线上结果。

因此，manifest 最终没有作为最终训练数据格式，而是作为：

```text
伪标签质量审计工具
样本分档工具
策略验证阶段
后续 clean rare 11 类标签构建的参考
```

同时还尝试过：

```text

pole / street light / utility pole → pole_light
```

### 6.2 12 类阶段

在扩展标签阶段，项目曾形成包含 `computer` 的 12 类或近似 12 类伪标签体系。这个阶段的目标是提升类别覆盖范围，尤其尝试补充工业场景、垃圾桶、窗户、门、围栏、路灯杆、摩托车等原始 6 类无法覆盖的目标。

## 7. 第七阶段：CLIPSeg 11 类训练与局限

在 11 类 clean rare 伪标签形成后，项目首先继续尝试 CLIPSeg 路线。CLIPSeg 的优势是：

```text
结构清晰
训练较快
天然支持 image + text prompt
可作为开放词分割基线
```

在 v5-opt 中，项目对 CLIPSeg 做了较完整的优化，包括：

```text
prompt pool
轻负样本
BCE / Dice / Focal
rare oversample
每类阈值
多 prompt 融合
按类连通域后处理
红外图像预处理
threshold sweep
```

其中，轻负样本策略设置为只保留一小部分 `hit=false` 样本，并显著降低负样本权重，避免拒识过强导致 recall 被压低。

但实验过程中发现，CLIPSeg 虽然能作为较稳定基线，但分数提升空间有限；尤其在引入更多 rare 类后，模型对复杂红外结构、小目标和弱纹理目标的表达能力不足。因此后续主线逐步转向 ESAM-CCLIP。

## 8. 第八阶段：ESAM-CCLIP 主线确立

### 8.1 6 类 ESAM 基线

在 6 类阶段，ESAM + Chinese-CLIP + 自定义 decoder 路线训练出了比 CLIPSeg 更好的基线表现。这说明 EfficientSAM 图像编码器在红外图像边界、小目标和局部结构上具有更强的先验能力。

因此，项目主线从 CLIPSeg 转向 ESAM-CCLIP。

### 8.2 11 类热启动训练

转到 ESAM 后，项目尝试使用 6 类 ESAM 权重作为热启动，将模型扩展到 11 类 clean rare 标签。由于 ESAM 训练速度明显慢于 CLIPSeg，最初只进行了约 3 轮 11 类热启动训练。

这个阶段结果不理想，可能原因包括：

```text
11 类标签更复杂
rare 类分布不均
computer 删除后类别竞争关系变化
热启动轮数不足
模型尚未充分收敛
fullset 与 split 训练策略尚未完全验证
```

### 8.3 后续不同参数训练取得新高

在初始 11 类热启动基础上，项目继续尝试了不同参数版本，包括 A、A-lite、lite、mid 等路线。后续两版不同参数的 11 类训练取得了新的分数高点，说明 ESAM-CCLIP 主线具备继续压分的潜力。

ESAM-CCLIP-11 文档中说明，该路线的核心实现包括：

```text
冻结 image encoder
冻结 text encoder
只训练 decoder
使用 prompt prototype
构建 text embedding cache
从旧 6 类权重热启动
支持 train/val 对照
支持 fullset 收尾
```

### 8.5 prompt prototype 与 text cache

11 类中部分类别文本表达不稳定，例如：

```text
trash can
window
door
fence
pole_light
motorcycle
```

因此 ESAM-CCLIP-11 中引入了 prompt prototype。做法是为每个类别配置多个 alias，对每个 alias 进行文本编码、归一化，再对同类 embedding 平均并归一化，最终得到每类唯一的 prototype embedding。

例如：

```text
trash can:
  trash can / garbage bin / trashbin / rubbish bin / 垃圾桶

pole_light:
  pole_light / pole light / street light / lamp / light pole / 路灯 / 灯杆
```

这样可以减少文本侧噪声，保持类别表达稳定，并降低训练时反复文本编码的开销。

### 8.6 dataset 构建

ESAM-CCLIP-11 的 dataset 逻辑针对伪标签格式做了适配：

```text
过滤 computer
过滤不在 11 类内的 prompt
过滤空 mask
训练阶段允许少量负样本
验证阶段默认不加负样本
RLE 解码后缓存为 png
cache key 使用 image_path / prompt / ann_id / rle_hash
```

这种设计避免了同一张图、同一类别、不同实例或不同伪标签版本之间的缓存冲突。

## 9. 第九阶段：A / A-lite / A-mid / lite 等 ESAM 优化分支

在 ESAM-CCLIP-11 主线确立后，项目没有大改模型结构，而是主要围绕训练策略进行优化，包括：

```text
采样比例
rare oversample
class weights
负样本比例
默认热启动权重
text cache
sweep 输出路径
```

### 9.1 A-mid 分支

`A-mid` 是 ESAM-CCLIP-11 体系下的一条 11 类优化分支，定位在：

```text
方案 A rare recall 版
和
A-lite 保 old 精度版
之间
```

它不改模型结构、不改 decoder、不改类别顺序、不引入新 loss 或新 head，也不解冻 image/text encoder，本质上仍是：

```text
ESAM + ChineseCLIP + decoder-only
freeze image encoder
freeze text encoder
train decoder only
```



A-mid 的核心配置包括：

```text
OLD_CLASS_SAMPLE_RATIO = 0.55
RARE_CLASS_KEEP_RATIO = 1.0
RARE_OVERSAMPLE:
  trash can: 3
  window: 2
  door: 2
  fence: 3
  pole_light: 3
  motorcycle: 2
```

并通过 class weights 对 rare 类进一步加权。

### 9.2 当前 ESAM 继续压分方向

当前仍在尝试的 ESAM 压分方向包括：

```text
lite-fullset-polish:
  从当前最高分 lite 权重继续小学习率收尾。

split -> fullset:
  使用昨天 mid 分集续训最好权重作为热启动，
  先 split 短训，再 fullset 收尾。

rare-repair-lite:
  不改结构，专门修 window / pole_light / trash can / door / fence 等 weak rare 类。
```

这三条线的共同特点是：不重新发明模型结构，而是在已经证明有效的 ESAM-CCLIP-11 框架上继续优化训练策略。

## 10. 第十阶段：阈值 Sweep 与最终推理提交

训练得到权重后，项目通过 threshold sweep 对每类阈值和后处理参数进行搜索。当前 sweep 支持：

```text
safe 模式
recall 模式
max_samples_per_class
checkpoint 写回
```

文档中明确说明，当前 `sweep_thresholds_11.py` 保留新版 sweep 逻辑，并且 `inference.py` 是提交推理脚本，不建议随训练线频繁修改。

当前提交策略主要是：

```text
1. lite + recall sweep + 新 inference.py
2. mid 分集续训 + recall sweep + 新 inference.py
```

这样可以保证两条提交都使用相同推理脚本，使变量更干净，便于比较权重路线差异，而不是推理脚本差异。

## 11. 当前阶段总结

截至目前，项目已经完成了以下工作：

### 11.1 伪标签阶段

```text
1. 多组 prompt 实验，确定初始 6 类标签；
2. 基于 SAM3 teacher 生成 prompt-style 伪标签；
3. 制作可视化浏览器，人工抽查每类标签质量；
4. 做图像质量分析、坏图清理和 denylist；
5. 对 teacher 伪标签做新旧版本对比；
6. 将 6 类伪标签进一步分成 A/B/C 三档；
7. 构建 manifest 做样本准入、权重和 mask 来源选择；
8. 发现 manifest 过度提纯会损失 recall，最终未作为主训练输入；
9. 重新可视化选择新类别，构建 12 类/扩展类别伪标签；
10. 删除学习效果差的 computer，最终固定为 clean rare 11 类。
```

### 11.2 模型阶段

```text
1. CLIPSeg：
   作为早期稳定开放词分割基线，后续做过 11 类 opt 优化。

2. ESAM + Chinese-CLIP + 自定义 decoder：
   6 类阶段表现优于 CLIPSeg，后续成为最终主线。

3. YOLO-World + FastSAM：
   效果不是最终最优，但训练快，主要用于验证小目标、尾类、类别不平衡和数据增强策略。

4. DINO + EfficientSAM：
   作为两阶段检测分割路线保留探索，但因速度风险不是当前优先提交线。
```

### 11.3 当前主线

当前最终主线为：

```text
ESAM-CCLIP-11
  EfficientSAM image encoder
  Chinese-CLIP text encoder
  FiLM fusion decoder
  11 类 clean rare 标签
  decoder-only 训练
  prompt prototype
  text cache
  fullset / split bridge
  recall sweep
  新 inference.py 提交
```

## 12. 可以放进论文的最终技术叙事

最终论文中可以将项目技术路线概括为：

```text
首先，我们基于 SAM3 teacher 对多组候选 prompt 进行验证，结合激活率、平均置信度和人工可视化结果，确定初始 6 类伪标签体系。随后，我们构建了伪标签可视化浏览器和坏图清理流程，对不同类别的伪标签质量进行人工抽查和自动诊断。

在学生模型阶段，我们依次尝试了 CLIPSeg、ESAM + Chinese-CLIP + 自定义 decoder、YOLO-World + FastSAM 等路线。YOLO-World 训练速度较快，因此被用于快速验证类别不平衡、小目标和尾类数据增强策略；CLIPSeg 作为早期开放词分割基线表现稳定，但上限有限；ESAM-CCLIP 在 6 类阶段取得更优表现，因此后续被确定为主线模型。

针对初始伪标签噪声问题，我们进一步对 6 类伪标签进行新旧 teacher 对比和 A/B/C 三档质量分级，并构建 manifest 进行样本准入与权重分配实验。实验表明，过度提纯会降低目标召回，因此 manifest 最终未作为训练输入，而是作为伪标签质量审计和策略验证工具。

之后，我们通过可视化和规则筛选补充 rare 类标签，形成扩展类别体系。由于 computer 类样本稀少且学习不稳定，最终将其从主训练类别中剔除，固定为 11 类 clean rare 标签。最终模型采用 ESAM-CCLIP-11，即 EfficientSAM 图像编码器、Chinese-CLIP 文本编码器和 FiLM fusion decoder，并通过旧 6 类权重热启动、prompt prototype、decoder-only 训练、rare oversample、fullset 收尾和 recall-oriented threshold sweep 进行优化。
```
