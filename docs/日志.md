**赛题二：红外智感 — 红外开放世界全模态分割**

### 1. 任务定义（输入→输出）

- **输入**：一张红外（或可见光）图片 + 一句文字提示（text prompt）
- **输出**：目标物体的**二值分割掩码**，并按指定格式写入 `predictions.json`

示例：

- 图片：红外场景图
- 提示：`"发热的绝缘子"` / `"草丛里的车"`
- 输出：对应目标的黑白掩码 + 按 `ann_id` 对齐的 JSON

### 2. 核心硬性要求（必须满足）

1. **用 SAM-3 作为知识源**（官方给权重）
2. **模型轻量化**：最终模型 **≤300M 参数**
3. **开放世界泛化**：训练 5 类场景，测试含**未知场景**
4. **极小目标敏感**：能检出 **<8×8 像素** 的小目标
5. **自监督 / 弱监督**：提供 **5 万 + 无标注红外图**，自己做标注 / 学习
6. **交付形式**：Docker 容器 + `inference.py`，**固定路径、固定接口**

### 3. 提交 & 评测要点

- 你的代码必须在：
  - `/raytron/code/` 放代码
  - `/raytron/code/model/` 放模型权重
  - 读取 `/raytron/test/` 下图片 + `test_tasks.json`
  - 输出 `/raytron/test/predictions.json`
- 评测看：**mIoU、小目标召回、推理速度、模型大小**

## 🔍 第一步：理解数据与基线性能

**先摸清数据底牌**：

- 5万+红外图像目前有标注吗？有的话是什么格式（COCO格式还是其他）？
- 标注的类别有哪些？覆盖什么场景（电力巡检、安防、自动驾驶等）？
- 数据集如何划分？官方要求使用提供的训练集，最终用闭集测试集评测

**跑通baseline不是为了立即训练，而是为了**：

- 验证环境配置和推理链路正确
- 理解模型在红外场景上的零样本表现水平
- 作为后续所有改进方案的**性能基准线**

建议：用baseline在官方测试集上生成一次 `predictions.json`，记录下mIoU等指标作为**对照基线**。

## 📊 第二步：数据准备与格式转换（核心前置工作）

SAM3的微调需要**prompt-mask pair**格式的训练数据：

- 原始RGB/红外图像（`.jpg` 或 `.png`）
- 对应的二值掩码图（单通道，像素值0为背景，255为目标区域）
- 文本提示（英文，如 "car", "person"）

**如果官方给了红外数据集的标注，需要先做格式对齐**：

- SAM3官方训练数据基础设施要求COCO格式标注
- 如果你的标注是VOC格式（XML），需要编写转换脚本转为COCO格式
- 需要一个将mask编码为COCO RLE格式的函数（你的 `inference.py` 中已有 `mask_to_rle` 可用）

如果是无标注数据，你需要考虑伪标签方案（详见后续章节）。

## 🚀 第三步：性能提升的四个方向

### 方向一：参数高效微调（最推荐，性价比最高）

全参数微调SAM3参数量极大（图像编码器占~82%计算量），代价高。建议采用**参数高效微调**：

| 方法                      | 原理                                             | 适用场景                       | 显存需求 |
| :------------------------ | :----------------------------------------------- | :----------------------------- | :------- |
| **SAM3-Adapter**          | 在冻结ViT的self-attention和MLP后注入轻量适配器   | 红外小目标、伪装目标、医学图像 | ~8GB     |
| **LoRA微调**              | 低秩适配器注入，保持原始权重冻结                 | 通用场景、快速适配             | ~8GB     |
| **Spatial Concatenation** | 将support和query图像拼接到共享画布，SAM3完全冻结 | 少样本场景                     | 低       |

研究显示：**从零样本到微调，性能提升显著，随后增益递减**，说明适度的标注努力可能就足够了。红外图像与RGB存在明显的模态差异，直接应用SAM3效果有限，微调正是解决这一差距的关键。

### 方向二：推理效率优化

虽然比赛更看重精度，但最终评分也考察推理效率。可以提前规划：

| 优化方法                      | 效果                                                    | 实现成本 |
| :---------------------------- | :------------------------------------------------------ | :------- |
| **批处理（Batch Inference）** | 构造批处理提示，多目标同步分割，显著提升吞吐量          | 低       |
| **TensorRT转换（FP16）**      | 显存↓65%（~6-7GB→~2.4GB），推理速度↑~2.5x（1.6s→~0.6s） | 中       |
| **INT8量化（PTQ）**           | 显存↓75%，推理速度↑~2.3x                                | 中       |

### 方向三：模型架构改进（潜力较大）

| 方向                    | 说明                                                         | 来源参考            |
| :---------------------- | :----------------------------------------------------------- | :------------------ |
| **SAM3-Adapter for IR** | 针对红外伪装目标等下游任务的轻量适配器，超越SAM/SAM2方案     | arXiv 2511.19425    |
| **EfficientSAM3蒸馏**   | 渐进式分层蒸馏，轻量学生模型（RepViT/TinyViT），适合边缘部署 | arXiv 2511.15833    |
| **DEAR红外小目标增强**  | 多尺度嵌套+中心差分卷积+正交动态融合，专门针对红外小目标分割 | The Visual Computer |

DEAR的三个核心模块理论上可以部分迁移到SAM3框架中，用于增强红外场景下的深层特征提取。

### 方向四：数据增强与伪标签策略

**数据增强**：

- 亮度变换：模拟不同光照条件（红外图像关键）
- 几何变换：旋转、镜像翻转、裁剪
- 基于SAM的目标增广：先分割再调整亮度角度

**伪标签策略**：

- 用SAM3在**无标注数据**上生成伪标签，扩充训练集
- 分阶段自训练：弱标注→模型预测→伪标签精化
