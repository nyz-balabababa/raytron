# CLIPSeg v3 最终全集训练配置总结

## 1. 当前结论

当前版本已进入最终全集训练阶段，train+val 合并训练 12 类。

```text
train + val 合并后的全集 label (trainval_label.json)
train + val 合并后的图片路径 txt (trainval_list.txt)
12 类 CLIPSeg 训练
普通 pred_json 模式，不使用 manifest
val 仅为训练参考指标，不代表真实泛化
```

---

## 2. 最终训练大类

```python
CLASSES = [
    "person",
    "car",
    "building",
    "tree",
    "animal",
    "computer",
    "trash can",
    "window",
    "door",
    "fence",
    "pole_light",
    "motorcycle",
]
```

| 最终类名 | 来源 |
|---------|------|
| `person` | 原始主类 |
| `car` | 原始 car + `truck` + `bus` 合并 |
| `building` | 原始主类，后处理做小连通域清理 |
| `tree` | 原始主类，后处理做小连通域清理 |
| `animal` | animal 映射后的主类 |
| `computer` | 原始 computer + `laptop` / `monitor` / `keyboard` 补充 |
| `trash can` | `dustbin` / `garbage bin` 映射合并 |
| `window` | 新增独立类 |
| `door` | 新增独立类 |
| `fence` | 新增独立类 |
| `pole_light` | `pole` / `street light` / `utility pole` 合并 |
| `motorcycle` | 电动车/摩托车，独立训练 |

不单独训练：`truck, bus, dustbin, garbage bin, pole, street light, utility pole, laptop, monitor, keyboard`（已映射进最终 12 类）。

```python
PRED_JSON   = ROOT / "test" / "clean_rare" / "label" / "trainval_label.json"
```

## 4. 训练策略

```python
USE_MANIFEST = False
APPLY_SCORE_FILTER = False
IMG_SIZE = 768
BATCH = 4
EPOCHS = 25          # 最多 25 轮
PATIENCE = 5         # 连续 5 轮 mIoU 不提升则早停
DEVICE = 0
WORKERS = 8
```

优化器：

```python
DECODER_LR = 1e-4
BACKBONE_LR = 1e-5
WEIGHT_DECAY = 0.03
WARMUP_EPOCHS = 2
LRF = 0.01
```

Loss：

```python
BCE_WEIGHT = 1.0
DICE_WEIGHT = 1.0
LOSS_WEIGHT_FLOOR = 0.7  # 仅作用于正样本，负样本不被 clamp 抬高
```

---

## 5. 负样本策略

```python
INCLUDE_NEGATIVE_SAMPLES = True
NEGATIVE_SAMPLE_RATIO = 0.15
NEGATIVE_SAMPLE_WEIGHT = 0.30
```

说明：

- `0.15` 比例，train+val 合训后正样本多，负样本不需要太高
- `0.30` 负样本权重，**不会被 LOSS_WEIGHT_FLOOR(0.7) 强行抬高**（v3 已修复：只对正样本做 floor 保底）
- 验证集负样本已关闭：`include_negatives=False, negative_ratio=0.0`

## 8. Prompt 动态增强

每个类 10~12 条 prompt 变体，包含英文、中文、中英混合短语。训练时 `PROMPT_AUG_PROB = 0.5` 随机替换。

---

## 9. v3 训练脚本特性

```text
✅ 普通 pred_json list，不使用 manifest
✅ trainval 全集训练，val 仅参考
✅ 早停：PATIENCE=5，连续 5 轮不提升自动停止
✅ 断点续训：自动检测 last.pt / best.pt 恢复
✅ 负样本权重不会被 LOSS_WEIGHT_FLOOR 抬高
✅ tiny 配置从 config import，不硬编码
✅ mask cache 按文件 hash 区分，不同 label 不会复用旧缓存
✅ 每 epoch 首 batch 打印正负样本 weight 检查日志
✅ 数据增强：HFlip + 随机 prompt + 反色统一
```
