## 里面应该重点写什么

### 1. 项目背景与任务理解

写清楚：

```
任务：红外图像开放词/文本提示分割

### 2. 数据与伪标签构建

这是你项目里工作量最大的地方，要写出价值。

可以按这个逻辑写：

```
Teacher 伪标签生成
  → 初始 5/6 类
  → rare 类补充
  → manifest尝试(训出来的效果一般，要写但不要着重写，一笔带过)
  → animal 映射
  → computer 剔除
  → 最终固定 11 类
  → selected_hit / selected_rle / include_in_train 清洗格式
```

最终 11 类要明确写：

```
person, car, building, tree, animal,
trash can, window, door, fence, pole_light, motorcycle

建议放一个表：

### 4. 最终模型结构

重点写最终主线，不要把所有失败路线铺太多。

推荐写：

```
最终采用 EfficientSAM + Chinese-CLIP + FiLM decoder。
EfficientSAM image encoder 负责提取图像特征。
Chinese-CLIP text encoder 负责 prompt 语义编码。
FiLM decoder 融合图像与文本特征，输出单 prompt 对应 mask。
训练阶段冻结 image encoder 和 text encoder，仅训练 decoder。
```

然后写为什么这么做：

```
相比纯 CLIPSeg：
  ESAM 图像特征对红外边界和小目标更稳。

相比 DINO 两阶段：
  推理链路更短，速度更友好。

相比重新训练大模型：
  参数量和训练成本更可控。
```
