# 当前可尝试路线总结

## 1. 当前提交线

现在提交策略固定为两条，不再拆太碎：

1. `lite + recall sweep + 新 inference.py`
2. `昨天的 mid 分集续训 + recall sweep + 新 inference.py`

这样做的好处是：

- 两条提交都使用同一套新推理脚本，变量更干净。
- 对比结果时，更接近于比较“权重路线差异”，而不是“推理脚本差异”。
- `recall` 已经从日志上略微优于 `safe`，所以当前优先拿 `recall` 版本提交。

## 2. 关于 sweep 脚本能不能直接跑 lite

可以。

- `src/ESAM-CCLIP-11-mid/sweep_thresholds_11.py` 可以直接拿来跑 `lite` 权重。
- 前提是：
  - 模型结构一致，都是当前这套 `EfficientSAM + ChineseCLIP + FiLM decoder` 的 11 类单权重。
  - 类别顺序一致。
  - 显式传入正确的：
    - `--checkpoint`
    - `--text_cache_path`
    - `--val_json`
    - `--val_list`
    - `--output_dir`
    - `--write_back_path`

建议：

- 不要靠脚本顶部默认值切换路线。
- `D:` 和 `E:` 两份工程并存时，更要全部显式传参，避免写回错目录。

## 3. 当前主判断

根据你现在已有结果：

- `lite` 仍然是主线。
- `fullset` 对你这条 ESAM 路线已经被证明是有效增益来源。
- `mid 分集续训` 仍然值得提交验证，但当前地位更像：
  - 对照线
  - 或者后续热启动底座

所以现在不是“放弃分集”，而是：

- 主押 `lite`
- 保留 `mid 分集续训` 做真实榜单验证
- 训练上并行开几条线继续找更强底座

## 4. 三条训练主线

下面三条是当前最值得并行跑的主线。

### 4.1 训练线一：lite-fullset-polish

目标：

- 从当前最高分 `lite` 权重继续抠分。
- 不改结构，沿着已经验证成功的 `lite + fullset` 路线继续做小步优化。

建议做法：

- 小学习率
- 短 epoch
- 稍长 warmup
- 不做大改动，只做稳定收尾

这条线的意义：

- 这是最稳的主线。
- 你已经证明了 `lite + fullset` 能到当前最高分，所以最值得继续压资源。

### 4.2 训练线二：split -> fullset 桥接线

目标：

- 先利用分集/分级续训得到更干净的中间权重。
- 再接一段短的 `fullset`，争取同时吃到：
  - 分集的干净
  - 全集的覆盖

建议做法：

- 用昨天分集续训最好的权重做热启动
- 再接短 `fullset`
- 训练风格尽量贴近 `lite`

这条线的意义：

- 这是当前最值得验证的桥接方案。
- 如果单纯分集训不如 `lite + fullset`，这条线有机会折中出更优结果。

### 4.3 训练线三：rare-repair-lite

目标：

- 不追求先把整体结构翻掉。
- 专门修当前最弱的 rare 类：
  - `window`
  - `pole_light`
  - `trash can`
  - `door`
  - `fence`

建议做法：

- rare 类样本质量优先
- rare 类伪标签准入收紧
- rare 类 oversample 可以继续保留
- rare 类负样本冲击单独更保守

这条线的意义：

- 你现在的短板已经比较清楚，不需要平均用力。
- 这条线更像“补坑线”，未必立刻最高分，但很可能给后面更强热启动底座。

## 7. lite 跑 recall 的命令模板

把下面的 checkpoint 替换成你的实际 `lite` 最佳权重路径即可：

```bash
python src/ESAM-CCLIP-11-mid/sweep_thresholds_11.py \
  --checkpoint <你的lite权重.pt> \
  --text_cache_path test/cache/text_emb_11.pt \
  --val_json test/clean_rare/label/val_label.json \
  --val_list test/val_list.txt \
  --sweep_mode recall \
  --max_samples_per_class 500 \
  --output_dir test/train_output/threshold_sweep_lite_recall \
  --write_back_path model/submit-lite-recall/sam3.pt
```
