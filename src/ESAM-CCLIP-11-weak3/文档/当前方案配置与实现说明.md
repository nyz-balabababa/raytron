# 当前方案配置与实现说明

## 1. 目录定位

当前实验目录是：

```text
src/ESAM-CCLIP-11 - weakwindow/
```

这是从原始 `src/ESAM-CCLIP-11/` 复制出来的独立副本。

当前原则：

- 不修改原始 `src/ESAM-CCLIP-11/`
- 不修改任何伪标签 JSON
- 所有 weak-window / weak3 相关实验只在当前副本目录中实现

当前这套副本里，已经同时存在两层逻辑：

1. `weakwindow` 通用控制逻辑  
   通过 `disabled_train_classes / class_keep_ratio / class_loss_scale` 控制训练样本和 loss。

2. `weak3` 默认策略  
   对 `window / door / pole_light` 做确定性弱化采样和弱化 loss 权重。

目前代码实际效果是：

- 训练仍保持官方 11 类
- 推理仍保持官方 11 类输出
- `window / door / pole_light` 在训练阶段被弱化
- `sweep` 新增了 `weak3_safe` 模式和弱类分析指标

## 2. 当前主假设

当前分支验证的核心假设是：

```text
window、door、pole_light 这三类在伪标签中容易和 building / car / fence 等共享特征发生干扰；
如果训练时弱化这三类，可能让 decoder 更集中地学习 old5 和更稳定的 rare 类，
从而提升整体榜单分数。
```

其中强度排序是：

- `window` 最弱
- `door` 次弱
- `pole_light` 轻弱化

## 5. dataset 中的实际实现

文件：

- [dataset_esam_cclip_11.py](/d:/nyz/raytron_project/src/ESAM-CCLIP-11%20-%20weakwindow/dataset_esam_cclip_11.py)

### 5.1 通用弱化参数

Dataset 已支持三个通用参数：

```python
disabled_train_classes=None
class_keep_ratio=None
class_loss_scale=None
```

它们的行为是：

- `disabled_train_classes`
  - 训练阶段直接跳过该类样本
- `class_keep_ratio`
  - 训练阶段按比例随机保留
- `class_loss_scale`
  - 在 `LOSS_WEIGHT_FLOOR` 之后再乘 loss 缩放

### 5.2 weak3 确定性采样

Dataset 当前新增了：

```python
weak3_enabled=False
weak3_seed=0
weak_class_keep_ratio=None
weak_class_loss_weight=None
```

并实现了：

```python
def deterministic_keep(key: str, keep_ratio: float, seed: int) -> bool:
    s = f"{seed}|{key}".encode("utf-8")
    value = int(hashlib.md5(s).hexdigest()[:8], 16) / 0xFFFFFFFF
    return value < float(keep_ratio)
```

当前 key 组成是：

```text
image_path | class_name | ann_id_or_rle_hash
```

因此特点是：

- 同一份数据集每次运行保留结果一致
- 不会因为 random seed 漂移导致每次训练样本不一样

### 5.3 weak3 的实际执行顺序

正样本当前处理顺序是：

1. 先判断 prompt 是否属于当前 11 类
2. 先做 `weak3` 的确定性 keep/drop
3. 再做 `disabled_train_classes`
4. 再做 `class_keep_ratio`
5. 再构造 `sample_weight`

当前 `sample_weight` 乘法顺序是：

```python
sample_weight = max(score, LOSS_WEIGHT_FLOOR)
sample_weight *= weak_class_loss_weight
sample_weight *= class_loss_scale
```

这意味着：

- weak3 会优先生效
- 之后如果你又传了 `class_loss_scale_json`，还可以在 weak3 基础上进一步缩放

### 5.4 当前 dataset 日志

当前 dataset 会输出：

- `positive_raw`
- `positive_kept`
- `positive_rebalanced`
- `dropped_by_disabled`
- `dropped_by_keep_ratio`
- `dropped_by_weak3`
- `final_sample_count`
- `avg_sample_weight`

所以现在可以直接通过日志检查：

- `window / door / pole_light` 是否真的被降采样
- 其他类是否基本稳定
